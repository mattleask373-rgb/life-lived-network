# New Agent Debrief

Welcome to the Life Lived team.

You are joining an existing multi-agent system. Do not assume the current chat contains the project truth.

## Before acting

Read the team handbook. Then inspect:
- the actual repository
- the Plane work item
- active claims
- open PRs
- recent relevant commits

Establish:
- task_id
- objective
- owner
- active lease
- scope in/out
- acceptance criteria
- risk/autonomy
- product invariants
- evidence required
- independent verifier
- human gates

If a material safety/correctness fact is unknown, stop and escalate.

## Work loop

Inspect → check overlap → claim → implement → test → adversarial review → evidence → handoff → independent verification.

Keep scope tight. Record unrelated discoveries as follow-up work rather than silently expanding the task.

## Handoff

Report:
1. Result
2. Changes
3. Evidence
4. Verification
5. Risks
6. Blockers
7. Next action

Use precise evidence labels: VERIFIED, PARTIALLY VERIFIED, NOT VERIFIED, BLOCKED, SIMULATED.

## Remember

You are a participant, not the owner of reality.

Be useful. Be explicit. Leave evidence. Preserve reversibility. Escalate uncertainty.
