# 24/7 Search Research Plan

## Objective
Continuously discover high-value local intent opportunities using historical and current evidence, then turn only validated opportunities into bounded engineering/growth tasks.

## Priority model
1. Local intent + strong real-world evidence + actionability
2. Local intent + strong demand + supply gap
3. Locality expansion where multiple intent families are supportable
4. Freshness/quality repair of existing surfaces
5. Broader informational demand where Living World can add unique utility

## Initial research families
- what's on / events
- things to do
- local services
- jobs
- classes and workshops
- community projects
- journey / route queries
- time-specific queries
- help / capability queries

## Historical + current evidence
Use multiple evidence classes rather than one keyword-volume number:
- historical search trends
- current search suggestions/observed query patterns where permitted
- first-party Living World queries
- Search Console once available
- licensed SEO/search datasets where available
- locality/entity coverage
- freshness and actionability

Every signal must record source, observation date and confidence.

## Worker cycle
RESEARCH → NORMALISE → CLUSTER → VALIDATE LOCALITY → CHECK REAL DATA → SCORE OPPORTUNITY → CREATE TASK → REVIEW → IMPLEMENT → MEASURE

## Hard safety/quality gates
- no fabricated demand
- no fabricated inventory
- no invented availability
- no invented qualifications
- no autonomous mass publishing
- no doorway pages
- no duplicate keyword-variant pages
- no bypass of canonical discovery
- no production merge by research workers

## Core hypothesis
Niche local queries such as “what's on in {locality}”, “{service} {locality}”, “{job/service} near {locality}”, and time-specific variants are valuable because they connect explicit local intent to a real-world action. Their value should be measured by downstream actions, not page count.

## First experiments
A. What's-on locality surface
B. Local service discovery surface
C. Time-specific local discovery
D. Local jobs/opportunities
E. Community/project discovery

For each experiment measure:
- impressions
- clicks
- indexed/served pages
- meaningful actions
- contact/invite/go/save/join actions
- new supply/provider participation
- freshness failures
- zero-result rate
- real-world action where measurable

## 24/7 boundary
Research workers may create evidence-backed opportunities and bounded tasks. They must not publish unsupported facts, alter security/RLS, bypass CI, merge protected production changes, or infer sensitive personal information.
