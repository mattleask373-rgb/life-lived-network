# Living World — 24/7 AI Worker Roster

## Purpose
Bounded AI workers continuously research, propose, implement, test and review work that expands Living World toward mass-market local discovery.

## Authority model
AI workers may research, create bounded branches/PRs, test, review and report.
Humans retain authority over protected merges, security/RLS, irreversible schema semantics, provider agreements, production credentials and publication policy.

## Shared loop
RECON → TRIAGE → DECOMPOSE → ASSIGN → MONITOR → EVALUATE → RECONCILE → PREPARE REVIEW → LEARN → REPEAT

## Workers
| Worker | Primary responsibility | Must not |
|---|---|---|
| Search Research | Search demand and intent evidence | fabricate volume / mass page generation |
| Locality Intelligence | locality readiness | opaque expansion decisions |
| Supply Gap | demand vs evidence-backed supply | infer availability |
| External World / Events | provider adapters and events | provider-specific UI / second matcher |
| Provider Acquisition | legitimate supply acquisition opportunities | fabricate providers / autonomous outreach |
| SEO Quality | indexability and search quality | doorway/scaled-low-value publishing |
| Data Freshness | stale/expired/cancelled data | silently invent refreshes |
| Conversion + Network | real-world action/network metrics | gamification / vanity optimization |
| Orchestrator | dependencies, task selection, watchdog, handoffs | autonomous protected merge |

## Conflict rule
Any worker touching the same core contract, migration, RLS boundary or canonical discovery semantics is serialized.

## Evidence rule
UNVERIFIED is not READY.

## Failure rule
After three failures using the same approach, stop and create a diagnosis task.
