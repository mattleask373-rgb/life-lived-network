# Global growth architecture

The canonical product path remains:

**Need -> canonical supply engine -> SupplyResult -> presentation/action**

The acquisition path is:

**real-world intent -> useful entry point -> possibility -> action -> participation -> network effect**

## Local discovery

Queries such as "gardener Brixton", "Airbnb cleaner Byron Bay", or "barber Lake District" are acquisition intents, not supply records. A search intent becomes authoritative product state only after explicit user action or an authorised ingestion path.

Local pages must be useful when visited directly. A keyword alone is not evidence.

## Indexability

Scalable local pages require real evidence, freshness, a canonical route and a meaningful action. No thin locality-by-keyword page factory is permitted. Never invent providers, jobs, availability, reviews, events or community records.

## External systems

External APIs feed Living World through adapters, validation, provenance, freshness and policy controls. The canonical supply engine must not make arbitrary external calls for every search.

## Growth intelligence

Growth opportunities include SEO, local discovery, useful content, partnerships, APIs/integrations, referrals, locality expansion, supply acquisition, demand acquisition, conversion and retention. A growth opportunity is a proposal, not permission to publish, spend, contact users or change production.

## 24/7 workers

Bounded roles should eventually cover research, SEO/local discovery, content, product growth, partnership/API scouting, locality expansion, experiments, analytics, quality/trust and orchestration.

Shared domain kernels, migrations, RLS and security boundaries remain serialised.

## Autonomy

0 observe; 1 propose; 2 build; 3 test; 4 human approval; 5 limited pre-approved automation.

Production merges, sensitive schema/RLS changes, new integrations, paid campaigns, large-scale publication and legal/policy-sensitive actions remain human-gated.

## Non-goals

No second matcher. No vector/graph/ML matching. No fake local inventory. No fabricated availability. No autonomous production merges. No spam outreach. No fake reviews/testimonials. No privacy-invasive journey exposure.
